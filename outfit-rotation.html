Quick workflow

Basic setup

  1. Upload images. The first image becomes the person.
  2. Every image after that becomes an outfit layer.
  3. Select an outfit from the list before editing it.

Align mode

  • Use Body X / Body Y to place the outfit on the person.
  • Use Fit scale, Fit rotation, and Opacity to fine-tune the fit.
  • Arrow keys nudge by 1 px. Hold Shift for 10 px.

Orbit preview

  • Spread controls how far outfits travel left and right.
  • Depth controls the front/back perspective effect.
  • Front lock is optional. Keeping it at 0% avoids overlap.
  • H hides an outfit from the orbit. S solos one outfit.

Export

  • Export PNG saves the current view.
  • Export PNG sequence ZIP renders the orbit as numbered PNG frames.
  • Save project stores all images and settings so you can reopen the setup later.
Best workflow: align each outfit first, then switch to Orbit preview and export.
