Cloud sync

Connect a GitHub Gist to sync this collection across devices.

Setup guide · GitHub token & cloud sync
  1. Create a token. A ghp_… token is a GitHub personal access token (classic). Open GitHub’s token settings, name it “Archived Releases,” choose an expiration, select only the gist scope, then generate and copy the token. Keep it somewhere safe; GitHub shows it once.
  2. Create the cloud file. Sign in to the same GitHub account at gist.github.com. Create a file named state.json with {} as its contents and choose Create secret gist. If you already have a sync Gist, reuse it. Copy the final ID from its URL: gist.github.com/your-name/GIST_ID.
  3. Connect this device. Export a backup first using the controls in Settings. Paste your token and the Gist ID into the fields above, then select Pull & sync. A new, empty Gist receives this device’s collection.
  4. Connect another device. Open this page there, enter a token for the same GitHub account and the same Gist ID, then select Pull & sync before editing. You can reuse your token or create a separate one for that device.

Everyday use. Changes upload after a short delay while this page is open. Opening the page checks the cloud; use Pull & sync before switching devices. Sync uses the newer collection rather than merging simultaneous edits.

Covers. Cover URLs sync with your collection. Uploaded cover images stay on their original device; use Export portable archive and import it on the other device to transfer those images.

Privacy. Your token is remembered in this browser’s local storage. Keep it private and replace it here if it expires. A secret Gist is unlisted; anyone with its URL can read it. Keep tokens out of the Gist.

Having trouble? Check the Gist ID, the token’s expiration and gist scope, and that the Gist belongs to the token’s account.

How release checks work
